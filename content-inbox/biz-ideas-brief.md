## 前三名
### 1. Grok Bot 抄作业包
- **MVP（3–5 天）**：从 800 个模板和 8×15 场景里挑 30 个，各配「做什么→粘贴提示词→Routine 节奏→额度注意」，出中文/英文 PDF 和 Notion 版；免费送 3 个换邮箱。
- **怎么赚钱**：$9 标准版 / $29 Pro（加 10 个 Routine 和避坑清单）；国内 ¥29–69。首单用 Gumroad（10%，有 Discover 曝光），或 Creem（3.9%+$0.40，可提现到支付宝）。
- **自动化**：网页工坊从 templates.json 生成产品文件；站内每个案例/模板页底部自动插入 CTA。
- **风险**：免费模板随处都有 → 卖点只能是「精选 + 实测 + 按场景」；注意 Grok Bot 品牌用法。
- **什么时候砍**：上线 14 天落地页访问不到 300 或 0 单 → 改成免费引流；30 天不到 5 单 → 砍。
- **获客**：X 发线程「800 个模板里真能省时间的 10 个」（免费给 3 个）→ 用 $30–50 推广表现最好的一条；小红书/即刻/V2EX 发中文版；Reddit 只发免费精华。
### 2. UI Hub Pro
- **MVP（2–4 天）**：提交表单 → 付款链接 → GitHub Action 自动生成条目；Featured 位加显眼标记；另做一个 $15 的「AI 生成 UI 提示词 + 资源清单」包。
- **怎么赚钱**：加急收录 $19–29，Featured $39/周（参考 DirectoryLaunch 的实测路径：第 2 个月 $19 提交，有 3 个首周付费）。
- **自动化**：提交、付款、上架和到期下架全程自动。
- **风险**：GitHub Pages 流量低时卖不动 → 外联时必须附真实流量。
- **什么时候砍**：外联超过 50 封仍 0 付费 → 只保留资源包。
- **获客**：每天冷邮件 5 个 UI 库/组件作者（附位置截图和数据）；在 X 发「本周新收录」@作者；提交到各 awesome 列表换外链。
### 3. Always-on Agents 周报 + 赞助位
- **MVP（3 天）**：用 Beehiiv/Kit 搭好，首刊 = 本周新模板 + 3 个 X 案例 + 额度变化；全站加订阅框。
- **怎么赚钱**：5k 订阅以下，主位中位价约 $150/期（bookasponsor）；定价约为订阅数的 2.5–5%，分类位约是主位的 25–35%（Paved）。本月先直接卖 $25–50 分类位给 agent 工具方。
- **自动化**：站点数据变化自动生成草稿，人工花 30 分钟润色。
- **风险**：冷启动订阅少，月内首单不确定 → 作为 #1 的放大器，不单独承担现金目标。
- **什么时候砍**：6 周订阅不到 300 → 改月报。
- **获客**：用 #1 的免费 3 个模板做引流；直接联系 rakazo、botdirectory 等 agent 工具作者。

**现金兜底**：#6 落地页代做，一单 $199 就是首笔，作品集用 usage.incidental.site。

## 收款现实（简）
- 大陆个人、没有海外主体：首选 **Creem**（3.9%+$0.40，个人走支付宝提现，审核 24–48h，被拒不能复审）或 Waffo Pancake。Paddle 可以个人注册（5%+$0.50），但电汇能否到大陆银行要先问清。https://shipkit.sh/zh/blog/stripe-vs-creem-vs-paddle-vs-lemon-squeezy ・ https://gaome.de/posts/indie-developer-payment-platforms-cn/
- Stripe 需要香港或美国主体（Atlas）；Lemon Squeezy 的提现名单里没有大陆，且正在并入 Stripe Managed Payments，新项目不建议用。https://www.lemonsqueezy.com/blog/2026-update
- Gumroad 抽 10%，带 Discover 市场，适合第一笔数字商品；大陆提现路径要先确认。https://makerstack.co/compare/gumroad-vs-lemonsqueezy/
- 国内：面包多 / 小红书店铺 / 知识星球（费率未逐一核实）。
