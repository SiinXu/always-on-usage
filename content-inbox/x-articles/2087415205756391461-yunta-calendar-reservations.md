# 走在停车场时，Bot 帮我订好了位子

> 本文根据 @yunta_tsai 在 X 上的公开帖子整理（2026-08-12），非作者本人撰写；文中不含虚构引语，数据均以原帖为准。

## 日程里那些“到时候再订”的事，最后都成了麻烦。

2026-08-12，X 用户 @yunta_tsai 分享了自己用 Grok Bot 做的一件事：Bot 扫描日历找出还没预订的事项，判断最佳时间并在网站上完成预订。这条帖子获得了约 986 个赞、76 次转发。

## 发生了什么

按原帖描述，作者没有写复杂脚本，而是把任务直接交给一个常驻的 Bot：给它目标、连上需要的工具，让它在自己的云电脑上执行，关键动作再回来找人确认。这正是 Grok Bot 与普通聊天机器人最大的区别——它不止给建议，而是把活干完。

## 为什么行得通

Bot 有自己的浏览器，没有 API 的预订网站也能操作，把日历和执行连在一起。另外，Bot 跑在云端，关掉电脑也不中断；跑通一次后可以存成 skill，再挂成 routine 定时执行。

## 怎么抄作业

1. 连接日历
2. 指令：找出需要提前预订但还没订的行程
3. 让 Bot 用浏览器完成预订，付款前确认
4. 每周跑一次

小建议：先手动跑一次、确认结果靠谱，再自动化；涉及付款、删除、对外发送的动作一律保留人工审批，并留意 routine 频率对用量的消耗。
