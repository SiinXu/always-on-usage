# Box：企业内容上的信贷委员会材料包

> 本文根据 @Box 在 X 上的公开帖子整理（2026-08-11），非作者本人撰写；文中不含虚构引语，数据均以原帖为准。

## 企业文档海洋里，Bot 怎么干活？

2026-08-11，X 用户 @Box 分享了自己用 Grok Bot 做的一件事：通过 Box MCP 跨受管内容整理材料并写回 Box。这条帖子获得了约 242 个赞、34 次转发。

## 发生了什么

按原帖描述，作者没有写复杂脚本，而是把任务直接交给一个常驻的 Bot：给它目标、连上需要的工具，让它在自己的云电脑上执行，关键动作再回来找人确认。这正是 Grok Bot 与普通聊天机器人最大的区别——它不止给建议，而是把活干完。

## 为什么行得通

MCP 直连受管内容，权限与合规保留。另外，Bot 跑在云端，关掉电脑也不中断；跑通一次后可以存成 skill，再挂成 routine 定时执行。

## 怎么抄作业

1. 连接 Box MCP
2. 说明材料包结构
3. Bot 汇总后写回指定文件夹

小建议：先手动跑一次、确认结果靠谱，再自动化；涉及付款、删除、对外发送的动作一律保留人工审批，并留意 routine 频率对用量的消耗。
