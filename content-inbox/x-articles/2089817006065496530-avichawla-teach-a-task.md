# 把屏幕操作变成 Agent 技能

> 本文根据 @_avichawla 在 X 上的公开帖子整理（2026-08-18），非作者本人撰写；文中不含虚构引语，数据均以原帖为准。

## 最懒的自动化：做一遍就行。

2026-08-18，X 用户 @_avichawla 分享了自己用 Grok Bot 做的一件事：介绍 Teach a task：亲自做一遍，Bot 自动写成 skill。这条帖子获得了约 106 个赞、14 次转发。

## 发生了什么

按原帖描述，作者没有写复杂脚本，而是把任务直接交给一个常驻的 Bot：给它目标、连上需要的工具，让它在自己的云电脑上执行，关键动作再回来找人确认。这正是 Grok Bot 与普通聊天机器人最大的区别——它不止给建议，而是把活干完。

## 为什么行得通

对没有 API 的网页流程尤其有效。另外，Bot 跑在云端，关掉电脑也不中断；跑通一次后可以存成 skill，再挂成 routine 定时执行。

## 怎么抄作业

1. 在 Bot 对话中开启 computer view
2. 选择 Teach a task 并完整操作
3. 编辑生成的技能草稿后再定时

小建议：先手动跑一次、确认结果靠谱，再自动化；涉及付款、删除、对外发送的动作一律保留人工审批，并留意 routine 频率对用量的消耗。
