# 教 Bot 一次，以后它来更新 WordPress

> 本文根据 @mrfundman 在 X 上的公开帖子整理（2026-08-18），非作者本人撰写；文中不含虚构引语，数据均以原帖为准。

## 不写脚本，也能自动化 CMS。

2026-08-18，X 用户 @mrfundman 分享了自己用 Grok Bot 做的一件事：用 Teach a task 演示 WordPress 更新流程。这条帖子获得了约 107 个赞、7 次转发。

## 发生了什么

按原帖描述，作者没有写复杂脚本，而是把任务直接交给一个常驻的 Bot：给它目标、连上需要的工具，让它在自己的云电脑上执行，关键动作再回来找人确认。这正是 Grok Bot 与普通聊天机器人最大的区别——它不止给建议，而是把活干完。

## 为什么行得通

演示即编程：Bot 记录界面操作生成 skill。另外，Bot 跑在云端，关掉电脑也不中断；跑通一次后可以存成 skill，再挂成 routine 定时执行。

## 怎么抄作业

1. 打开 Bot 的电脑视图，选 Teach a task
2. 完整演示一次更新流程
3. 检查生成的 skill，补充审批点

小建议：先手动跑一次、确认结果靠谱，再自动化；涉及付款、删除、对外发送的动作一律保留人工审批，并留意 routine 频率对用量的消耗。
