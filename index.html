Scheduled routines, email/webhook, chat, Bot-to-Bot messages
Browser or connector
Built-in cloud browser + many connectors (Gmail, Calendar, Notion, GitHub…); browser steps cost the most
Parallelism
Many Bots in parallel, can spawn sub-agents; parallel count is the main quota multiplier
Routine frequency
Minutes to daily; frequent polling burns quota fastest
Good for
Multi-Bot teamwork, email/calendar triage, browser research and form prep
Not for
Second-level monitoring, scraping farms, unattended high-frequency browser loops

  • What got built · MultipleOne shared mailbox so AI agents message each otherThe author set up a mailbox for AI agents on a MacBook with 433 addresses, one per agent, and added rules to each agent: check mail on start, send a note to another agent saying what is needed and why, do the work and reply when a note arrives, treat a note as a request and never a yes, and never put passwords or keys in a note. Five apps (T3 Code, Grok Bot, OpenBot, Muse and Dot) each sent a note to every app and got replies, 25 out of 25; a note from Muse got a reply about a minute later.lennox_saint2026-11-26
  • Guides · Grok Bot7 ways to use email aliases to assign work to Grok BotThe author explains adding a label before the @ in a Grok Bot email address (for example bot+travel@): mail still lands in the same inbox, but the label tells the bot which job it belongs to. Seven uses: +receipts for an expense log, +reading for a weekly newsletter digest, +travel for a trip page, +shipping for a parcel tracker, +school for a weekly family brief, +alerts for grouped service alerts, and +leads for an enquiry log with draft replies. A prompt is included that asks the bot to confirm the alias, propose the setup, and test on one email after approval.Michael_Fenech_2026-11-26
