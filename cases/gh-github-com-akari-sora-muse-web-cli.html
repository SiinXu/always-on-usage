muse-web-cli: a command line for your own Meta Muse web session

akari-soraGitHub ↗Posted 2026-11-08Added 2026-11-08 23:41 UTC

What it does
An unofficial CLI for your own logged-in Meta Muse web session in a dedicated Chrome profile: status, messages, side chats and sends with file attachments. Not affiliated with Meta, part of trinity-cli, built with Playwright and Python.
