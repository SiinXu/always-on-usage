Steps / points from the source
  1. mcp.json: Phone Bud's hosted MCP server, https://www.phone-bud.com/mcp, with your API key in the Authorization header.
  2. skills/phone-bud/SKILL.md: when to call, confirming with the user first, writing the request, calling a list, and limits. The same file is served at https://……
  3. Create an API key in Phone Bud under Settings, Developer.
  4. Install the plugin and set PHONE_BUD_API_KEY to that key.
  5. US and Canada numbers only. Calls end at 30 minutes, including hold time.
  6. The agent says it's an AI if asked, and never claims to be a person or the user.
  7. It can't transfer the call to the user, receive calls, or pay for anything.
  8. Call only people and businesses you have a reason to contact. See the acceptable use policy and privacy policy.
