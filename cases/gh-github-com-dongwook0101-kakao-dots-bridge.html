What it does
An experimental open-source project for macOS that creates event-driven KakaoTalk work-message drafts for ChatGPT Dots. Business use only, and draft-only by default.

Steps / points from the source
  1. 고정된 업무 앱·계정·실행 프로세스·실제로 열린 DB를 매번 확인합니다.
  2. 기본 대상은 /Applications/KakaoTalkNew.app,
  3. 개인용/업무용 구분을 추론하는 제품이 아닙니다. 위 앱에 별도의 본인 업무
  4. 원본 DB는 읽기 전용이며, 메시지 조회 자체는 카카오톡 UI의 읽음 처리와 다릅니다.
  5. 자동 초안은 텍스트만 최대 20개로 제한합니다. 첨부파일, 음소거 방,
  6. 이벤트에는 대화방 ID·메시지 ID·시각만 넣습니다. 본문은 필요할 때 별도 도구로 읽습니다.
  7. Dots용 MCP에는 조회 4개와 초안 저장 1개만 있으며 발송 도구가 없습니다.
  8. 최신 대화 지문을 다시 확인하며, 같은 맥락의 초안을 자동으로 덮어쓰지 않습니다.
