Steps / points from the source
  1. A Next.js command centre plus a FastAPI control plane, deployed as one Vercel project (/ UI, /api backend).
  2. A provenance pipeline: source observation → claim → obligation → plan block → on-screen approval → demo calendar event.
  3. A specialist bot layer (Orchestrator, Scout, Verifier, Planner, Guardian, Monitor) that cannot bypass policy.
  4. A reusable G1 humanoid stage for the live console.
  5. Not a homework-completion agent.
  6. Not institutional surveillance or cohort scoring.
  7. Not a silent calendar writer. Spoken “yes” is not a write.
  8. Open termpilot.org (or local http://127.0.0.1:3000).
