# ChatGPT Dots 现在值得用了：一个 dot 协调多台电脑

Source: https://www.youtube.com/watch?v=0Eps-MTY0Mg

Author: James Layne

作者说最新更新让 dot 可以连接多台电脑，并直接给每台电脑上的 Codex 代理发消息，在一个聊天里（手机上也行）协调本地项目。他在笔记本、带 RTX 5090 的 Windows 台式机和 Mac Studio 三台电脑上测试：查看家里跑的编码基准、把 Codex 线程切换模型重新评分、再让 Mac Studio 上的代理用电脑操作试玩游戏。Dots 至少需要每月 100 美元的 ChatGPT Pro 方案。

What it does
The latest update lets a dot connect to multiple computers and message the Codex agents on each one, coordinating local projects from a single chat, even on a phone. He tests it on a laptop, a Windows desktop with an RTX 5090 and a Mac Studio: checking a coding benchmark running at home, switching a Codex thread to another model to re-grade it, then having an agent on the Mac Studio play-test his game with computer use. Dots needs at least the $100/month ChatGPT Pro plan.
