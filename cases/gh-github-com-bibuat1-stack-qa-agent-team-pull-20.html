# Grok Bot 账号完整备份要附工作交接

Source: https://github.com/bibuat1-stack/qa-agent-team/pull/20

Author: bibuat1-stack

QA 代理团队把完整备份约定写进仓库：周备份或换号全量备份的压缩包必须附带当时的交接文档，固定六项——已做与待做及查看位置、待用户拍板的事、连接器与账号清单（只写名称和状态）、PR 与现网技能版本对照、角色名与旧 id、进行中产物索引。多账号同步先列差异、等用户确认，不自动覆盖。

What it does
A QA agent team wrote its backup rule into the repo: every weekly or account-switch full backup must include a handover with six fixed items: what is done and next and where to look, decisions waiting for the user, connectors and account labels (names and status only), open PRs versus live skill versions, role names and old ids, and an index of work in progress. Multi-account syncs list differences and wait for the user instead of overwriting.

Risks and limits
  • Deletes, unsubscribes or cancels things: get a list first and confirm each item
  • Scheduled runs keep consuming usage: start at a low frequency and raise it once it is stable
  • Several bots in parallel: usage adds up per bot, so merge bots with similar jobs first
  • The author's result may not reproduce for you; the original post is the reference
