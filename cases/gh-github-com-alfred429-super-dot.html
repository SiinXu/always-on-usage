  1. A personal knowledge vault: Personal, Family, Work, Hobbies, Money and Wellbeing.
  2. Memory and reflection: “Note it,” source-linked knowledge, morning prompts and evening journals.
  3. Focused help: brainstorming, Grill Me, Prompt Master, debugging, Ponytail and i-have-adhd.
  4. Room to grow: project starters, skill creation/vetting, research, routines and gentle vault care.
  5. Connected creation: Notion, Apple Keychain guidance, hosting, web research and Hyperframes.
  6. Planning and content: ClickUp, n8n social-media automations and Higgsfield premium media.
  7. Ongoing care: vault/Notion organisation, daily storage reports, instruction review and grouped
