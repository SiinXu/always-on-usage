What it does
This docs PR records a spike: ChatGPT Work chats and dots subscribe to MCP Events by webhook, while Claude’s hosted products only call tools, and atc answers neither server/discover nor any events/* method. It recommends building delivery for ChatGPT in a later issue. Events is still the draft SEP-3415 extension.

Steps / points from the source
  1. Claude Code reports its state on its own, through a settings file atc passes at spawn, and
  2. Grok Build and Codex CLI take a one-time hook install that atc prints for you
  3. A Claude-compatible backend runs as its own agent in the same fleet
  4. Attention routing. Sessions that need you sort to the top, and a Claude session's statusline
  5. Sessions outlive the daemon. A restart, or an upgrade with u, brings every session back from
  6. Agents that drive agents. atc mcp hands any agent the fleet as MCP tools, so it can spawn,
  7. Hosted assistants. atc mcp --http serves the same tools to ChatGPT or Claude.ai behind
  8. Several machines. atc-gateway serves the fleets of several daemons through one connector
