# webhook 唤醒的例行任务占了 3.5% 周额度

Source: https://github.com/ceragon/matt-loop/issues/52

Author: ceragon

开发者实测：Grok Bot 承接 webhook 通知的例行任务约占周额度 3.5%，用户主动对话约 6.6%（周上限 10%）。原因是每次唤醒都起一整轮 agent 并载入约 777 字的例程。可查方向：只在需要用户处理或出错时通知、合并重复通知、把例程缩短并按需读取细节。

What it does
A developer measured that the Grok Bot routine receiving webhook notifications uses about 3.5% of the weekly quota, versus about 6.6% for direct chats (weekly cap 10%). Each wake starts a full agent turn and loads a routine of about 777 characters. Options under review: notify only when the user is needed or on errors, merge duplicate notices, and shorten the routine with details read on demand.
