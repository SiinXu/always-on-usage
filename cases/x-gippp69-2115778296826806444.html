In the author's words

The author's post, quoted verbatim and left untranslated.

Prompt
Set up my launch team in Grok Bot: 7 bots, 1 clock. An idea shows up on X on Monday. By Friday it is dead with a written reason, or live with a domain, a deck and first users. I only approve money and posts. Target: about 60 runs a week by my math, not 1,176 from 7 hourly bots. Create the bots one by one and show me each prompt before you save it.

RULES
• Work only in /workspace/launch/, one folder per idea. Bots hand off through files, never email.
• Every bot reads the LEDGER file first and starts only when the step before it is DONE. Then it adds: time | bot | DONE | file | next bot. Stuck: BLOCKED plus reason, message me.
• Log every X search in the X reads file, run the budget script first. STOP means stop. Limit: 1,000 X reads a day, 30 a minute.
• Facts get a source link, guesses get GUESS. Never invent numbers, quotes or users.
• Never post, send, buy, pay or delete without my approval. Posts stay drafts. If I deny a card, drop it.

THE 7 BOTS
1. Chief (primary): never does the work. Keeps a "Launch Board" Page. 08:30 brief only if the LEDGER changed.
2. Scout (the only clock): Monday 09:00 or "run scout". Searches X (max 400 reads) for "just launched", "wish there was", "why is there no", plus GitHub Trending, Show HN, Product Hunt. Top 15 table, sends me the top 3.
3. Pain Miner (on Scout DONE): public complaints for the top 5 (max 300 reads), mentions x intensity, 3 source links each.
4. Judge (on Pain Miner DONE): real pain, one 10x number, 7 day v1, first 50 users, 0 to 2 each. 7+ GO, 5 to 6 HOLD, 0 to 4 KILL with one line why.
5. Builder (on GO plus my "build"): SPEC, v1 with tests, ONE pull request, fixes failed checks until merge. I merge.
6. Pitch (on Builder DONE): 7 slide deck, X post, 5 post thread, 30 second video script, 3 reply drafts. Drafts only.
7. Buyer (on Builder DONE or my "buy"): domain, hosting or one API key. Cap $40 per idea, $100 a month. 3 options with renewal price, I approve each one. No auto-renew trials.

1 CLOCK, 6 TRIGGERS
Clock: Monday 09:00 Scout.
Triggers: Scout DONE starts Pain Miner • Pain Miner DONE starts Judge • the pull request starts Builder fixes • mail to a +alias starts Inbox • an @bot tag on X adds to the queue • mail to +meme starts the watch-only Meme Radar.
No other scheduled routines.

FINISH
Confirm the guards. Report the bots, the clock, the triggers and the run estimate by my math (about 60 a week vs 1,176). A test run does real work, so test on a copy. Run Scout once by hand, then wait for my approval.

Risks and limits
  • Involves payments, orders or bookings: let the bot draft first and act only after you confirm
  • Reads and writes your mailbox: grant read-only and draft access first, and approve before anything is sent
  • Deletes, unsubscribes or cancels things: get a list first and confirm each item
  • Scheduled runs keep consuming usage: start at a low frequency and raise it once it is stable
  • The author's result may not reproduce for you; the original post is the reference
