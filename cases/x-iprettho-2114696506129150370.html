Keeping several agents' memory in one Obsidian vault

@IPretthoX ↗Posted 2026-10-26Added 2026-10-26 12:44 UTC♥ 1

What it does
Wanting to try Grok Bot, Meta Muse, ChatGPT Dots and Hermes without re-explaining projects and preferences each time, the author moved each bot's memory, logs and workflows into one Obsidian vault of plain files they can read and edit. Every bot gets the same instruction: read the relevant files before answering, then save new information; a new agent pointed at the same vault picks up where another left off.
