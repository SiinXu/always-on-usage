Steps / points from the source
  1. Land the repo on the shared computer. Clone it if it is not already there. Done when PLAN.md and vault-template/ are on disk you can read.
  2. Ask the questionnaire in PLAN.md, in that order. Warn that a Reset can wipe the path before they pick an off-box copy. Display name, off-box copy, and GTD o
  3. Emit the setup prompt. Fill the PLAN.md templates the way src/fill.ts does. Do not write a new grammar. Done when the five descriptions and the first-task
  4. Copy the empty tree. Copy vault-template/ onto the chosen path (default /workspace/second-brain/). Keep tasks/ only when markdown is the live store. Dro
  5. Connectors first. If they picked Todoist or a Notion-class product, they install that connector in Settings before any roster bot exists. Done when they say i…
  6. Create the five bots. They use New → Create new agent → Bot actions → Edit Profile. You paste Conductor, Capture, Memory, Ops, and Research, one description e…
  7. One group chat with those five only. Done when the room exists.
  8. Routines the answers require. Every GTD option: monthly Memory decay (current unused 30 days proposed decayed). Hybrid or full: weekly review on Conductor
