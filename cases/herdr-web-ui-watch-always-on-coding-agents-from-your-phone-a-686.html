herdr-web-ui：在手机和浏览器上盯常驻编码 Agent

devswhaGitHub ↗

做了什么
Herdr 插件：把 Herdr 里的 Agent 窗格搬到浏览器和手机 PWA。Claude Code、Codex、OpenCode 等会话显示成聊天，一键切到真实终端（xterm）；审批和提问变成可点的卡片；Agent 需要输入或跑完时发 Web 推送；手机键条带 Esc/Tab/Ctrl/方向键；可通过 Tailscale/SSH 远程连。安装：herdr plugin install devswha/herdr-web-ui（需 Herdr ≥0.9.0，默认 localhost:7317）。TypeScript/React/Bun，MIT，约 900 星，2026 年 10 月 7–13 日一周新增约 300 星。
