做了什么
Herdr 插件：把 Herdr 里的 Agent 窗格搬到浏览器和手机 PWA。Claude Code、Codex、OpenCode 等会话显示成聊天，一键切到真实终端（xterm）；审批和提问变成可点的卡片；Agent 需要输入或跑完时发 Web 推送；手机键条带 Esc/Tab/Ctrl/方向键；可通过 Tailscale/SSH 远程连。安装：herdr plugin install devswha/herdr-web-ui（需 Herdr ≥0.9.0，默认 localhost:7317）。TypeScript/React/Bun，MIT，约 900 星，2026 年 10 月 7–13 日一周新增约 300 星。
Herdr 外掛：把 Herdr 裡的 Agent 窗格搬到瀏覽器和手機 PWA。Claude Code、Codex、OpenCode 等工作階段顯示成聊天，一鍵切到真實終端機（xterm）；審批和提問變成可點的卡片；Agent 需要輸入或跑完時發 Web 推播；手機鍵條帶 Esc/Tab/Ctrl/方向鍵；可透過 Tailscale/SSH 遠端連線。安裝：herdr plugin install devswha/herdr-web-ui（需 Herdr ≥0.9.0，預設 localhost:7317）。TypeScript/React/Bun，MIT，約 900 星，2026 年 10 月 7–13 日一週新增約 300 星。
A Herdr plugin that brings Herdr agent panes to the browser and a phone PWA. Claude Code, Codex, OpenCode and other sessions show up as chat with a one-click live terminal (xterm); approvals and questions become tappable cards; web push alerts fire when an agent needs input or finishes; a phone key bar adds Esc/Tab/Ctrl/arrows; connect remotely via Tailscale/SSH. Install: herdr plugin install devswha/herdr-web-ui (needs Herdr ≥0.9.0, default localhost:7317). TypeScript/React/Bun, MIT, ~900 stars, +~300 in the week of Oct 7–13, 2026.
