# 给忙不过来的 bot 配一个助手

Source: https://x.com/WheelerMan/status/2112668934969209226

Author: WheelerMan

作者的 DNA bot Helix 总卡在同一处：每个 bot 只有一个浏览器，它在一个网站上忙时其他事都得排队。于是作者建了第二个 bot Strand 专门帮 Helix，接手需要在浏览器里看的活，还能自己跑后台任务，让 Helix 同时推进更多事。

What it does
The author's DNA bot, Helix, kept stalling: each bot gets one browser, so while Helix was busy on one site everything else waited. A second bot, Strand, now takes anything that needs a visual look in a browser and runs its own background tasks, so Helix gets more done at once.
