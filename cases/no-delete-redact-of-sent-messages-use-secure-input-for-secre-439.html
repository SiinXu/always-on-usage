What it does
Staff (kevinn, 2026-09-17): Grok Bot cannot delete or redact a sent message (only failed-to-send messages have Delete)—rotate any pasted secret on the provider. Prefer asking the bot to request the credential: it shows a masked secure input card, stores the value as a bot secret, and keeps it out of the transcript and model context.
