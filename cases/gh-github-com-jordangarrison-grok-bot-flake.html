  1. grok-bot — the app, wrapped for NixOS (patchelf'd, GApps-wrapped,
  2. sand — a compatibility alias for the same binary. Older upstream releases
  3. share/applications/grok-bot.desktop + icon, so launchers and URL-scheme
  4. grok-bot.desktop must be on XDG_DATA_DIRS — true automatically once
  5. The scheme must map to the app. The app registers itself on first launch
  6. chrome-sandbox is removed. It only works setuid root, which the Nix
