# 自建 Tailscale + bot，对比 Dots 和 Grok Bot

Source: https://x.com/accelerate27/status/2125931703331901485

Author: accelerate27

作者比较了用 Tailscale 加自己的 bot 应用（需要自己配置）和 Dots 或 Grok Bot：后两者安装后就能直接运行，不用花力气设置，更易用。他也提到 Tailscale 本身设置简单，登录并把电脑加入同一 tailnet 即可，或让 Agent 代为设置。

What it does
The author compares Tailscale plus your own bot app, which you must set up, with Dots or Grok Bot, which just run after install with no setup effort and are much easier. He adds that Tailscale itself is easy: log in and put your PC on the same tailnet, or tell your agent to set it up.
