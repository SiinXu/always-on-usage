Steps / points from the source
  1. Read recent conversations, search message text, or dump one thread
  2. Cover all contacts, except chats you put on your blocklist
  3. Show contact names next to phone numbers and emails (from your Mac's Contacts, read-only)
  4. Print JSON to stdout
  5. Send, delete, or edit messages (this helper only reads)
  6. Edit your contacts or your blocklist
  7. Talk to the network
  8. Run in the background (it only runs when you or Grok Bot call imsg-read)
