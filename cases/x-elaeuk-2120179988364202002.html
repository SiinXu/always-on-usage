Dots on multiple computers: a second desk, and a bigger handover

@ela_eukX ↗Posted 2026-11-10Added 2026-11-10 23:41 UTC

What it does
OpenAI dots can now connect to several local computers, and you pick one per task, such as building and testing on a spare box while you code on your laptop. It is still Pro and up. The catch: each thread runs on one computer at a time, and there are no per-machine permissions, so one “Allow access” hands over that machine’s files, code and apps.
