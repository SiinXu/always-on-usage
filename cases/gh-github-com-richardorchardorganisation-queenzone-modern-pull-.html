Grok Bot rescues a failed Dependabot bump by migrating ~110 test files

richardorchardGitHub ↗Posted 2026-10-16Added 2026-10-16 11:12 UTC

What it does
Dependabot's @testing-library/react-native 14.1.0 bump failed typecheck with 264 errors. Grok Bot (draft by Codex, reviewed) moved the tests to the async API, touching test files only, and added helpers for removed APIs. Typecheck, lint, 1,350 Jest tests and expo-doctor 21/21 pass; no tests deleted or skipped.

Steps / points from the source
  1. Configuration key: PushNotifications:Apns:Environment
  2. Environment variable: PushNotificationsApnsEnvironment
  3. Accepted values are exactly sandbox or production (lowercase, no surrounding whitespace)
  4. When the setting is absent, Development defaults to sandbox and every other host environment defaults to production
  5. An explicit value always wins over the host default
  6. Do not add this key to shared appsettings.json; that would make it explicit in Development and defeat the absent-setting sandbox default
  7. Merge the PR and wait for deploy-dev.yml to complete (DEV member-auth and DEV journey then start via workflow_run).
  8. Confirm Nightly RealData, DEV member-auth, and DEV journey are green on that SHA.
