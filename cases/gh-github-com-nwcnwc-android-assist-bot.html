Open-source Android assistant: screenshot plus voice question to a Grok Bot

What it does
The open-source android-assist-bot sends an Android screenshot and a spoken question to a Grok Bot and shows the answer as a notification. It was inspired by Everest's Action Button Bot.

Steps / points from the source
  1. Open the link above on the phone.
  2. Allow the browser to install unknown apps when Android asks.
  3. Tap Install. Updates install over the same app only when they are signed with this certificate.
  4. Open the bot, then its details, then Routines.
  5. Add a webhook trigger and save the routine. Leave it Active.
  6. Open the routine again. The Webhook section has POST to, key, and header. Click a field to copy it.
  7. In Ask Button, paste POST to into Webhook URL.
  8. Paste header into Authorization header. You can paste the full Authorization: Bearer … line or only Bearer …. The app strips a leading Authorization: label a……
