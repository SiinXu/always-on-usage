After his limits were cut, he used T3 Code to build an open-source Grok Bot clone

Nick VasilescuYouTube ↗Posted 2026-11-09Added 2026-11-09 23:43 UTCviews 11,458

What it does
With his Grok Bot limits cut, the author used T3 Code as a software factory to reverse engineer Grok Bot and build an open-source clone (repo nickvasilescu/grokbot-clone), with every prompt on screen. The video shows an agent using Grok Bot via computer use and rebuilding the UI in Paper MCP in about 30 minutes, T3 Code running agents across 5 machines, and a clone with Google sign-in through Composio, Grok 4.7 via the xAI API, and each bot on its own Orgo computer.
