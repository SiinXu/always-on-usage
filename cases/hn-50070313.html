Helicon: an open-source desktop client for the Muse Code CLI

Harjot (harjjotsinghh)Hacker News ↗Posted 2026-10-13Added 2026-10-15 12:29 UTC▲ 2

What it does
The author uses Meta's Muse Code CLI daily and found many sessions across projects hard to manage in the terminal, so he built a desktop app and VS Code extension with Tauri 2 and React. It runs muse serve, reuses your muse login and plan, resumes terminal sessions, shows inline diffs to approve, and displays 5-hour and weekly limits. MIT licensed, v0.21.9, 9 contributors.

Steps / points from the source
  1. Projects grouped by directory the agent worked in (incl. isolated worktrees)
  2. Sessions/tasks per project with full history, resume, and diffs
  3. Approvals surfaced honestly (onRequest / promptUnmatched / denyUnmatched), never bypassed
  4. One codebase for desktop (Tauri) and web (same React UI against a remote daemon)
  5. Windows that actually works - runs Muse Code for Windows natively (no WSL), or Muse inside WSL2 with path translation if that is what you use
  6. A file viewer beside the thread - browse the project, read highlighted source, preview and edit Markdown, and view images, video and PDFs; paths Muse Code me……
  7. Your real plan meter - the 5-hour window and weekly cap as Muse Code reports them, in the sidebar and on the usage page
  8. Goals you can steer - set, pause, resume, change and clear a /goal from the goal panel or the composer

Risks and limits
  • Involves payments, orders or bookings: let the bot draft first and act only after you confirm
  • Uses a browser or website login: the costliest kind of step, so prefer a connector where one exists
  • Scheduled runs keep consuming usage: start at a low frequency and raise it once it is stable
  • The author's result may not reproduce for you; the original post is the reference
