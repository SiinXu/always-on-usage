Steps / points from the source
  1. Not the official download storefront
  2. Not a reconstructed client, prompt dump, or skill pack
  3. Isolation is per user, not per Bot. Screens are not a security fence.
  4. npm run build generates static HTML in dist/ and runs the checker.
  5. npm run check validates internal links, unique titles, one H1/canonical/description, and rendered counts 199/54/89/42.
  6. npm run preview or npm run dev serves dist/ at http://localhost:4173.
  7. With Python: use the build script above, then point Cloudflare Pages at the repo (or upload dist/).
  8. Without Python: dist/ is committed. Set Pages build to a no-op or upload dist/ as-is. Still rebuild when you change src/ or scripts/.

Risks and limits
  • Involves payments, orders or bookings: let the bot draft first and act only after you confirm
  • Uses a browser or website login: the costliest kind of step, so prefer a connector where one exists
