Steps / points from the source
  1. 6 read-only tools: status, chat list, messages, pending group replies, media retrieval, and group information
  2. 4 write tools for sending text, images, videos, or documents, all requiring an idempotencyKey
  3. 1 event: whatsapp.message_received
  4. OAuth 2.1 authorization code + PKCE, dynamic client registration, and refresh tokens
  5. Owner LID verification for direct messages, owner/Bot membership checks for groups, and verified mention/quote checks
  6. Bounded message storage, event queues, retries, deduplication, and security logging
  7. https://whatsapp.example.com/mcp
  8. https://whatsapp.example.com/admin
