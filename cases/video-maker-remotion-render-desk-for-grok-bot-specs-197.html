What it does

Steps / points from the source
  1. Escolhe um id só com letras, números e hífen (meu-video).
  2. Escreve public/specs/{id}.json no schema public/specs/schema.json. O campo id tem que ser igual ao nome do arquivo.
  3. Coloca a mídia em public/, com caminhos relativos a public/ no JSON:
  4. clipe de pessoa/produto falando → public/clips/
  5. still → public/assets/
  6. narração, música, sfx → public/audio/
  7. Gera os clipes de movimento fora daqui (HeyGen, Kling, Sora, filmagem). Este repo não chama nenhuma API de vídeo.
  8. Roda npm run validate {id} e corrige avisos de arquivo faltando.
