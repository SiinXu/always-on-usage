What it does
The author's CX bot reviews a backlog, commits a handoff file to a shared repo and messages Claude Remote, which runs Claude Code on their Mac; results return, 4 rounds that day. Work is sorted into three tiers for one-word batch approval, a chief-of-staff bot sends an hourly attention list from 9am to 9pm and skips quiet hours, and both tools write one changelog, where a self-audit found 2 gaps.
