Talking to an OpenAI dot from an in-house chat app via a Slack mirror

drsamdoneganGitHub ↗Posted 2026-11-13Added 2026-11-13 13:39 UTC

What it does
This PR lets an owner talk to their personal agent bot, such as an OpenAI dot ("Maek") installed through OpenAI's Slack app, from MLAI Chat exactly as in Slack. The owner's messages go out with their own Slack authorization, the bot answers in Slack, and replies come back through the private Slack mirror. It is off by default, matches exact Slack IDs only, accepts only the caller's own bot and requires AI consent before sending.

Risks and limits
  • Involves payments, orders or bookings: let the bot draft first and act only after you confirm
  • Deletes, unsubscribes or cancels things: get a list first and confirm each item
  • Uses a browser or website login: the costliest kind of step, so prefer a connector where one exists
