GitHub comments let ChatGPT Dots run lab jobs on the owner's Mac

danielbuvaGitHub ↗Posted 2026-10-27Added 2026-10-27 12:39 UTC

What it does
This PR lets a remote agent that works only through GitHub (ChatGPT Dots) run a fixed menu of lab jobs on the owner's Mac and phones via the owner's /lab comments, without game files leaving the Mac. The workflow responds only to the owner's comments on a self-hosted runner and comes with 8 host tests.
