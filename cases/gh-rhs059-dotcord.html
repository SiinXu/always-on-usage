Dotcord: a Discord connector for OpenAI Dots (now with Grokbot support)

RHS059GitHub ↗Posted 2026-10-10Added 2026-10-15 13:40 UTC

What it does
A Discord connector where one shared deployment onboards separate accounts, routes cross-account wakes without exchanging tokens and gives its owner admin visibility; the repo notes the October version added Grokbot support, with React UI, Worker backend and regression tests.

Steps / points from the source
  1. ChatGPT Sites identity/access enforcement and hosting, or an equivalent **trusted authentication gateway**
  2. A D1 binding named `DB`, with the included migrations applied in order
  3. Your own trusted owner-role configuration and Discord credentials, configured privately
  4. A compatible MCP Events subscription receiver and task service for sleeping-dot wakeups
  5. `client-build/index.html`: production single-file client
  6. `dist/server/index.js`: deployable Worker module, embedded UI, and downloadable client
  7. `dist/server/wrangler.json`: Sites build metadata with a placeholder physical D1 ID
  8. `dist/.openai/hosting.json`: logical hosting manifest
