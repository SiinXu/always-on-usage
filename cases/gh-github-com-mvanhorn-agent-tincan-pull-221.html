agent-tincan now recommends Grok Bot's managed Tailscale connector

mvanhornGitHub ↗Posted 2026-11-09Added 2026-11-09 23:43 UTC★ 1

What it does
This PR fixes the Grok Bot adapter docs: Grok Bot now ships a managed Tailscale connector, and its docs say not to install a Tailscale client on the bot's computer because it is wiped when that computer is replaced. The docs now recommend the managed connector, covering personal and company tailnets, joining with the relay's full MagicDNS name, and limiting access; the script gains TS_MODE=managed, and the self-installed userspace method stays as a fallback.
