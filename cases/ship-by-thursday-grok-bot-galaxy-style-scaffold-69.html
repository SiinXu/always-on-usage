Steps / points from the source
  1. Org + dominio — GitHub org vacía, dominio shipbythurs.day, lander desplegada en Vercel.
  2. Ops stack — Slack, Notion (handbook), Cursor + cloud agents, conectores de marketplace (X), Vercel.
  3. Bots con roles — no chats sueltos: cada bot tiene un puesto, memoria persistente y su propia máquina en la nube.
  4. Investigación de mercado — un bot escaneó respuestas en X, otro las sintetizó; el equipo filtró con: ¿quién es el cliente, qué dolor, cuánto vale?
  5. Idea — "pop-up OS for restaurants" (generada por un bot, refinada por humanos).
  6. Lander + waitlist — página pública + formulario que escribe a una base de datos y manda email de confirmación. *Antes* de saber el producto final.
  7. Inbox — hello@ funcional.
  8. Crea tu propia org/repo a partir de esta plantilla.
