# GrokBot Switch：只在你不用电脑时才借给 AI 智能体

What it does
The open-source desktop toggle GrokBot Switch lets AI agents borrow your PC only when you're not using it: green for Available, red for Do Not Disturb, with schedules, idle detection and an ask-first popup. Written in Python for Windows.

Steps / points from the source
  1. An always-on-top pill shows the current state. Click the pill to flip it by hand. Click – to shrink it to a 28px status dot; click the dot to bring the pill ……
  2. A settings window lets you add or remove schedule rules (days, start, end, Available or Do Not Disturb), turn on auto Do Not Disturb while you are using the ……
  3. If a bot is using the PC and you start typing or moving the mouse, the switch turns red, the bot’s lease is revoked, and the bot should stop and move the job……
  4. Right-click the pill (or the minimized dot) and choose Exit to close the switch. There is no system tray icon in this version.
  5. Copy this folder to a place on the Windows PC you want to share, for example %USERPROFILE%\GrokBotSwitch\.
  6. Run the app with pythonw so no extra console window stays open:
  7. Leave Start with Windows off unless you turn it on in settings. That option only adds a small file in your Startup folder. It does not use Task Scheduler.
  8. Exit 0 means go ahead. The JSON line includes lease_id.
