Steps / points from the source
  1. Create a new bot in Grok Bot, or open an existing one.
  2. Connect the X plugin and sign in once.
  3. Check your X API credit balance before running a big search. This is the step people forget, and the search silently returns nothing without it.
  4. Optional: name it something you will recognise in the sidebar. *Buying Signal Bot* works.
  5. Create an account at fullenrich.com and generate an API key.
  6. Put the key somewhere the bot can read it. On the Grok Bot machine: /home/box/.config/fullenrich/api_key
  7. What it costs: a people lookup is about 0.25 credit when a person is found. A work email is about 1 credit when found. Nothing is charged when nothing
  8. The rule that keeps this cheap: never enrich a post until it has survived the filters. Enrichment is the last step, not the first.

Risks and limits

  • Scheduled runs keep consuming usage: start at a low frequency and raise it once it is stable
