What it does
A self-hosted always-on agent project lists what a comparison with Grok Bot and OpenAI Dots showed was missing, and adds it: Claude and OpenAI-compatible APIs, external MCP, triggers from page/RSS changes and webhooks, text attachments and streamed replies.
