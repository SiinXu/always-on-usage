Steps / points from the source
  1. Sources: the Admin API and Store API references, plus the agent index at https://docs.medusajs.com/llms.txt.
  2. Tool: medusa_docs searches the official index or greps an official page. It refuses other origins.
  3. Skill: golden-rule-read-docs-first is step 0 of every skill (a test enforces this).
  4. Every endpoint the server calls was checked against the official v2 OpenAPI reference, and each tool result carries its doc link.
  5. Gaps get the label "not in official docs" and are marked UNVERIFIED (see docs/LESSONS.md).
