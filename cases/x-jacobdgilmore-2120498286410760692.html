Bots messaging each other burned through Grok Bot usage

@jacobdgilmoreX ↗Posted 2026-11-11Added 2026-11-11 13:44 UTC

What it does
The author built a similar multi-bot setup; his mistake was having each bot message the others, which burned usage significantly. On top of that, Grok Bot cut usage and re-routed traffic to cheaper models, which dropped code quality, and his bots ended up looping.
