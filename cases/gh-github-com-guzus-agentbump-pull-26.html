Have agents send a setup link instead of signing users up

guzusGitHub ↗Posted 2026-10-21Added 2026-10-21 22:43 UTC

What it does
A Grok Bot without the AgentBump connector browsed the site, started signing its human up and reached for Sign in with Apple in its own browser. This PR makes agents create a setup link for the person to finish on their own iPhone. In evals, the Apple sign-up request went from 0/3 on main to 3/3, and two other prompts passed 2/2.

Risks and limits
  • Reads and writes your mailbox: grant read-only and draft access first, and approve before anything is sent
  • Uses a browser or website login: the costliest kind of step, so prefer a connector where one exists
