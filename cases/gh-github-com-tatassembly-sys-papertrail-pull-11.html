What it does
A docs-only PR from Grok Bot adds agents/vscode/NEXT_TASKS.md, a self-contained brief for VS Code CLI agents: kickoff prompt, current state, rules, full gate, numbered milestones with steps, acceptance and test commands, and a handover. HANDOVER.md now marks VS1–VS5 complete, and the change is logged in the grokbot log.
