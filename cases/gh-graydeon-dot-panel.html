来源里的步骤 / 要点
  1. Independent Needs You queue with centered touch-answer dialogs, Later, persistent Dismiss, and exact-event history
  2. Owner-reviewed project/source modules with timestamps and honest empty states
  3. Saved portrait/landscape widget layouts: edit-only drag/resize, tap controls, swap, templates, paging, Save/Cancel, and previous-layout restore
  4. Compact Today and Week widgets opening a Month/Week/Day calendar dialog
  5. Owner-private calendar snapshots with timezone/DST handling and explicit date coverage
  6. Compact usage bars, reset dates, optional reset availability/expiry, and separate source timestamps
  7. Light/dark themes remembered on the device
  8. Source-configured reference and briefing links; no arbitrary API credential forms
