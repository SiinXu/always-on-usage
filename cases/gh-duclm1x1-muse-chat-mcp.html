做了什么
MCP 服务器加 OpenAI 兼容层，让你用自己的账户和额度从任何 MCP 或 OpenAI 兼容客户端使用 Meta Muse。由于 Muse 没有公开 API，它通过 Playwright 驱动你已登录的真实 Chrome；这类非官方接入可能受服务条款限制。

来源里的步骤 / 要点
  1. **MCP tools** over stdio — drop-in for Claude Desktop / opencode / any MCP host.
  2. **OpenAI-compatible HTTP shim** with **real streaming** (SSE), correct `finish_reason`, and `/v1` error objects.
  3. **Prompt-injected tool calling** — expose OpenAI `tools` to Muse and get `tool_calls` back.
  4. **Attachments** — send images/video with a prompt (MCP `files`, OpenAI `image_url` parts, CLI `-f`).
  5. **Sessions & media** — list/open/read/send in any Muse chat, and pull out the images/videos Muse generates (links + download).
  6. **Muse Manual** — a living guide to Muse's video/image/content capabilities at `manual/MUSE_MANUAL.md`, regenerated with `node manual/interview.mjs`.
  7. **Reuses your existing login** via a dedicated Chrome profile, or attaches to a Chrome you already run with `--remote-debugging-port=9222`.
  8. **Never kills your browser**: when attached over CDP it only *disconnects* on close.
