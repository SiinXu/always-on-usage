OpenAI Dot can now connect to several computers

@LdataengineerX ↗Posted 2026-11-11Added 2026-11-11 23:43 UTC

What it does
The author summarises OpenAI's docs: since 9 November a dot can connect to more than one computer and be told which one to use for a task. Setup: open the dot's profile in the ChatGPT app on each computer and select Allow under Computers. Examples include running Xcode tests on a spare Mac and comparing a test on a current and an older SDK. Limits: one computer per thread at a time, the machine must stay on and online with the ChatGPT app open, and no maximum is given.
