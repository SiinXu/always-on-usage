Grok Bot Anywhere: send files and notes to your Grok Bot from anywhere on the desktop

@ai_algoitX ↗Posted 2026-11-09Added 2026-11-09 13:41 UTC

What it does
An unofficial open-source client for macOS and Windows with a global floating composer, Finder and Explorer actions, drag and drop, and WeChat forwarding on macOS. Each bot can have its own entry points, delivery method and prefix, and a local inbox tracks delivery. It uses your own account and a protocol observed from the local client, so updates can break it; Windows is only partly verified, Linux is unsupported, MIT.
