Agent City — a 3D city of one user's Grok Bot assistants and their real work

RongleCat/awesome-grok-bot (GitHub) ↗

Title and summary are in the original language, not translated.

What it does
Public three.js city (live on GitHub Pages) where one user's AI assistants and 15 working roles such as Scout, Librarian, Council and Auditor show their real routines, saved skills, finds and activity log, grown by a Grok Bot about three sessions a day, with a review-and-apply feed for Grok Build and private email and calendar notes kept to the local copy.

Steps / points from the source
  1. index.html: small shell + loader. three.js comes from jsDelivr as ES modules; the city's own code is plain scripts
  2. css/style.css; js/core.js (helpers, renderer), js/roles.js, js/world.js, js/daynight.js, js/agents.js, js/panels.js, js/minimap.js, js/ui.js,
  3. js/buildings/*.js: one file per building (City.building({...})). New building = new file + add its name in js/manifest.js.
  4. data.js: generated by build_data.py (skills, agent profiles, routines, finds.json, activity.json, CHANGELOG.md).
  5. activity.json: append-only role log [{date, session, role, action, details, link?, needs_user?, course?, solution?}]. Real actions only.
  6. finds.json: [{date, title, url, source, why_useful, status: "new"|"approved"}]. Only things actually found.
  7. private.json -> private.js: gitignored, never pushed. Courier/Timekeeper/Auditor notes and private notices; loaded only on the local copy
  8. tools/screenshot.py: headless render check. tools/pace.py: weekly usage pacing (reads the local budget.json; numbers only). tools/treasury.py: Treasury nu

Risks and limits
  • Reads and writes your mailbox: grant read-only and draft access first, and approve before anything is sent
  • Uses a browser or website login: the costliest kind of step, so prefer a connector where one exists
  • Scheduled runs keep consuming usage: start at a low frequency and raise it once it is stable
  • The author's result may not reproduce for you; the original post is the reference
