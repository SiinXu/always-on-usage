Rome gives Dots and Muse an Assistants chat page

imsobearGitHub ↗Posted 2026-10-22Added 2026-10-22 22:41 UTC★ 1

What it does
This PR gives a guardian’s ChatGPT dots and Meta Muse, which talk to Rome through Rome Cloud, one chat each on a new Assistants page. The guardian can write first; those messages go to the assistant and wake no Rome agent. The page stays off the sidebar until added under Edit.
