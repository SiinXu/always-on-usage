Steps / points from the source
  1. Message — just chat. "Do this thing." Fastest way to start *and* to build a bot (it prompts the details out of you).
  2. Routine — "run weekdays at 9am," or wire a schedule / Slack message / GitHub event in the GUI. Test-run, disable, or edit anytime.
  3. Another bot — bots can trigger bots, so they're composable (group chats + orchestrator chains). See the last section.
  4. (You)* Ask in plain language; connect Twitter + Notion.
  5. (Bot)* Pulls followers — via the API if available, otherwise by opening each profile and reading the bio.
  6. (Bot)* Infers country + confidence from messy free-text locations, creates the Notion DB, writes a row per follower.
  7. (You)* Filter the DB by city when you travel; the bot stays available to re-run or extend.
  8. Connect Twitter/X and Notion in the bot's plugins.
