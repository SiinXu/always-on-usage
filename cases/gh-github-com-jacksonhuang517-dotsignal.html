DotSignal feeds Feishu and NetEase mail events to ChatGPT Dot

JacksonHuang517GitHub ↗Posted 2026-11-11Added 2026-11-11 23:43 UTC

What it does
The open-source project DotSignal turns Feishu messages, tasks and calendars plus NetEase email headers into cloud events, so ChatGPT Dot can remind you to reply, decide and follow up. Its repo tags describe a self-hosted MCP server using IMAP and OAuth2.
