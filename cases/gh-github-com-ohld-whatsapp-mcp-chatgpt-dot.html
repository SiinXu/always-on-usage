A self-hosted MCP server that connects ChatGPT Dot to WhatsApp

ohldGitHub ↗Posted 2026-11-13Added 2026-11-13 13:39 UTC

What it does
The repo is a self-hosted WhatsApp MCP server for ChatGPT Dot and ChatGPT apps: read chats, get incoming messages in real time via MCP Events webhooks, and send replies. It is stdlib-only Python on WAHA, with OAuth 2.1, allowlists, send caps and Docker Compose.

Steps / points from the source
  1. One file, zero dependencies. app.py is ~1,100 lines of Python standard library. Nothing to pip install, easy to audit.
  2. Push, not poll. Incoming messages are delivered to ChatGPT as MCP Events (Standard Webhooks HMAC, durable SQLite outbox, retries, replay cursor).
  3. Works with ChatGPT out of the box. OAuth 2.1 with Dynamic Client Registration and PKCE S256, Streamable HTTP transport.
  4. Privacy boundary on the server. Groups, status and channels never match. Read and send scopes, new-chat sending and the daily cap are set in env, never by th……
  5. Built on WAHA (GOWS engine). You link WhatsApp as a companion device; no Business API account needed.
  6. WAHA keeps a linked-device session and posts each incoming message to the bridge (HMAC-signed).
  7. The bridge stores messages from allowed chats, commits, then enqueues one event per matching subscription.
  8. A delivery worker POSTs events to ChatGPT's callback, in order per subscription, with exponential backoff.
