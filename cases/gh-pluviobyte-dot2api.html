Dot2API: expose your Dot as an OpenAI- and Claude-compatible API

PluviobyteGitHub ↗Posted 2026-10-06Added 2026-10-15 13:40 UTC★ 205

What it does
A self-hosted gateway that exposes one OpenAI Dot through OpenAI- and Claude-compatible APIs. The README warns that anyone holding a key can prompt your Dot and its connected apps, so issue keys only to callers you trust as yourself.

Steps / points from the source
  1. `api_key` is what callers put in their SDK.
  2. `dot_token` is what the Dot uses to reach the MCP endpoint.
  3. Add an MCP connector pointing at `https:///mcp` with `dot_token` as the bearer credential. If the connector cannot send an authorization header, start the serve
  4. Ask the Dot to watch the `task.available` event on queue `dot`.
  5. Give the Dot its standing instructions: list queued tasks, claim one, answer the conversation, complete the task.
