Steps / points from the source
  1. JSON-RPC 2.0. Stdio is newline-delimited. Streamable HTTP accepts a
  2. Negotiates 2024-11-05, 2025-03-26, and 2025-06-18; unknown client
  3. Methods: initialize, ping, tools/list, tools/call,
  4. Errors: -32700 parse, -32601 unknown method, -32602 bad
  5. Stdout carries protocol only — all logs go to stderr.
  6. Blocked topics: bot_safety_update with blocked_topics makes chat
  7. HTTP auth: set --auth-token before binding beyond localhost. Stdio
  8. Destructive tools are explicit: state_import replaces everything,
