InfoStation adds a Grok Bot handoff mode and X posts as a source

mawwalkerGitHub ↗Posted 2026-10-21Added 2026-10-21 12:42 UTC

What it does
A PR that lets Grok Bot run InfoStation on a schedule without an HTTP LLM API: each LLM call writes a request file with the full prompt and JSON schema and exits, the agent writes the answer, and the same run validates it and continues. X posts can feed story selection and scripts with attribution, while numbers found only in tweets are excluded from fact-checking. Premarket runs CPU-only.
