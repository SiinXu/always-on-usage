# 在 ChatGPT Dots 上运行 Meal Concierge 膳食规划

Source: https://github.com/poisdahl/meal-concierge/pull/444

Author: poisdahl

这个 PR 让 Meal Concierge 在 ChatGPT Dot 自己的云电脑上安装运行，跨轮次和更新保留家庭数据与命令记录，并补充安装、更新、排程和排错文档。作者在 Dots 中验证：同一私有云家庭原地更新，三人份菜单和库存扣减可重新打开，结账请求在应用启动前被拒绝，9 个前台和 2 个原生适配器测试通过。

What it does
This PR installs and runs Meal Concierge on a ChatGPT Dot's own cloud computer, keeps household data and command receipts across turns and updates, and documents setup, updates, scheduling and troubleshooting. Verified in Dots: the same private cloud household updated in place, a three-portion menu and pantry deduction reopened, a checkout request was refused before startup, and 9 foreground plus 2 native adapter fixtures passed.
