What it does
Summarising NebuSec's report: asking Muse to save an attacker-controlled page gave code execution in the agent container via a lagging Chromium with its sandbox off; the Sentinel egress guard let history and memories leave without approval; kernel exploits then gave VM root. NebuSec says all were patched; report and fix dates, any Meta statement and CVEs are not stated. Advice: patch the browser on the vendor's cadence, keep the sandbox on, and enforce egress outside the thing being attacked.
