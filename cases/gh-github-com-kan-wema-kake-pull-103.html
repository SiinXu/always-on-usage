Connecting Muse to your own MCP server: add its callback URL

kanGitHub ↗Posted 2026-11-17Added 2026-11-17 13:48 UTC

What it does
Registering a custom /mcp connector in Muse failed: Cloudflare Access Managed OAuth rejected dynamic client registration with 400 invalid_client_metadata because Muse’s callback was not an allowed redirect URI. The fix adds https://agent.meta.ai/api/hatch/oauth/callback to the allowed list and agent.meta.ai to the MCP clients allowed to write.
