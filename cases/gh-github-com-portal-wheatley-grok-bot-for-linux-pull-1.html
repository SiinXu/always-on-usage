Packaging the Grok Bot desktop app for Linux with Nix

portal-wheatleyGitHub ↗Posted 2026-11-11Added 2026-11-11 23:43 UTC

What it does
This PR packages the Grok Bot desktop app for x86_64 and aarch64 Linux as a Nix flake: it downloads the official Windows installer, unpacks it, runs it on Electron 42 from nixpkgs, drops the Windows native addons and rebuilds tree-sitter. On x86_64 under Xvfb the sign-in screen renders and the sign-in link opens, but it was not tested while signed in; aarch64 has not been run on hardware yet.

Steps / points from the source
  1. Unfree: Grok Bot is proprietary. The package is marked that way.
  2. Insecure: Grok Bot 0.79.4 is built for Electron 42. nixpkgs marks
  3. Download the official Windows installer from Cursor's CDN. Its version
  4. Unpack it with 7-Zip and unpack the app archive (app.asar) into a plain
  5. Delete every Windows native addon (.node, .exe, .dll).
  6. Rebuild the two addons the app cannot run without, tree-sitter and
  7. Put the app next to the matching Electron from nixpkgs (electron_42-bin).
  8. Wrap it with xdg-open on the PATH (for sign-in) and the usual Wayland
