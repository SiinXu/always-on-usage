Steps / points from the source
  1. En el repo de GitHub: Settings → Pages → Build and deployment → Source: GitHub Actions.
  2. Tras el deploy, la app estará en https://.github.io/llegadas-tarde/.
  3. Abrir la app → el campo de búsqueda queda listo.
  4. Escribir nombre o apellido → tocar el estudiante.
  5. Se registra la hora actual del dispositivo; se puede Deshacer el último.
  6. La lista de hoy se parte en Primaria y Secundaria (según level del CSV).
  7. Copiar primaria / Copiar secundaria generan textos planos para WhatsApp.
  8. Limpiar hoy borra solo los registros del día; no toca la nómina.
