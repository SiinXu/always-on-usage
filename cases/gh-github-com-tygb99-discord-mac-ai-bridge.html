Steps / points from the source
  1. gateway.ts keeps a Discord gateway connection and appends your messages from the bridge channels (and their threads) to inbox.jsonl.
  2. bridge.ts reads the inbox every 3 seconds, sends each message to the right app, and polls the apps for replies.
  3. bridge.ts --keeper runs every minute from a LaunchAgent. If the bridge heartbeat is older than 90 seconds it reopens the bridge in a herdr tab.
  4. helpers/pickle-bg.ts (optional) sends to Pickle and fetches attachments fully in the background, through the OmO desktop engine that OmO's computer-use tool ……
  5. helpers/pickle-send types into Pickle. Pickle ignores background key events and AX value setting, so the helper waits until you have not touched the keyboard……
  6. helpers/pickle-fetch gets an attachment that arrived from another device. It clicks the attachment bubble so the Pickle app downloads it itself. The bridge n……
  7. macOS on Apple silicon (Pickle is an iOS app running on the Mac). Developed and used on a recent macOS release.
