Steps / points from the source
  1. Chief coordinates only and has zero tools.
  2. Researcher produces claims, facts, uncertainty, and HTTP(S) sources.
  3. Director turns approved evidence into a timed treatment and shot plan.
  4. Render alone uses imagine-mcp, creates assets, and records every billable attempt.
  5. Editor independently approves or rejects the candidate.
  6. Publisher writes the work card and publication package, announces the human gate, and stops.
  7. Spend gate: Render makes no paid xAI API call without an explicit per-run human budget.
  8. Editorial gate: Publisher receives a run only after Editor explicitly says APPROVED; Editor can return REJECTED repeatedly.
