What it does
InvoicePilot is an AI accounts-payable agent on Meta Muse open weights. Drop in an invoice; it extracts facts, writes an audit script, runs it in a locked sandbox, and only pays the bank account already on file. Built for the Meta Global AI Developer Hackathon.
