What it does
The author rebuilt AgentRags as an evening paper made safe for Grokbot to run nightly: each pick gets a permanent story page; no hotlinked X or publisher media, only Grokbot’s illustrations or generated covers, with /api/needs-images.json as Grokbot’s work list; check_data.py runs before every build and fails on bad data so the last good deploy stays live; GROKBOT.md sets who may change what.
