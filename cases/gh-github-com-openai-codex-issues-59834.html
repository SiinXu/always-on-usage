Dots bug report: false completion claims, cloud/local confusion, an unexplained Paused state

MattU27GitHub ↗Posted 2026-11-06Added 2026-11-07 13:40 UTC

What it does
A user reports on GitHub that on November 6, while asking his dot to improve an existing job-research workflow on its cloud computer, it gave overly broad completion reports and then admitted unfinished work, used "local" ambiguously (its cloud computer or his PC), and the desktop app showed the whole dot as Paused although he had only paused the scheduled job search. He says this made it hard to trust what was done.
