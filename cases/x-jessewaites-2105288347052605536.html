Giving a Dot a physical body: an ESP32 with a tiny screen

@JesseWaitesX ↗Posted 2026-09-30Added 2026-10-15 03:19 UTC

What it does
Built in one morning: an ESP32 running Arduino firmware shows OpenAI's animated character. Hold the screen to talk; a relay on the Mac transcribes via ElevenLabs, types it into the Dot web interface, then voices the reply with ElevenLabs and sends audio back over Wi‑Fi.
