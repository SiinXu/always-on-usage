A locked-down SSH user for the Grok Bot box over WireGuard

carpenikeGitHub ↗Posted 2026-10-22Added 2026-10-22 22:41 UTC

What it does
This NixOS PR adds an unprivileged grokbot user on the host forge for the author’s cloud assistant box. It accepts key login only from WireGuard address 10.8.0.4, with no password and no forwarding, is not in wheel, and can read only what an ordinary user can. A companion PR lets that peer reach only forge:22. Nothing changes until merged.
