Steps / points from the source
  1. A Grok Bot that pulls live sleep, HRV, readiness, VO2, and runs when you message it
  2. After-run feedback: what went well, what to improve, what to do next
  3. Random stat questions (“VO2 max?”, “HRV last night?”)
  4. Optional season review by date range
  5. A Grok Bot account and a bot
  6. A Garmin Connect account
  7. uvx on the machine that will run the server (Grok Bot’s computer already can install it via the start command)
  8. Willingness to complete Garmin MFA on that computer, not in the chat
