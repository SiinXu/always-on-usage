BillBack: an agent that checks bills and emails vendors for refunds

Manasa-L-HegdeGitHub ↗Posted 2026-10-29Added 2026-10-29 22:37 UTC

What it does
The GitHub project billback is an AI agent built with Meta Muse Spark. It cross-checks a bill, a delivery slip and a voice note, catches overcharges, and negotiates a refund with the vendor by email.

Steps / points from the source
  1. Multimodal Bill & Slip Extraction: Extracts line items (name, quantity, rate, amount, total) from printed and handwritten invoices and delivery challans.
  2. Arithmetic Verification: Validates line-item math ($qty \times rate = amount$), subtotal consistency, and grand totals.
  3. Cross-Source Audit Engine: Cross-references invoices with delivery slips and agreed rate cards to catch unauthorized delivery fees, duplicate items, delivere……
  4. Autonomous Dispute Generation: Formulates clear dispute findings backed by exact mathematical proofs.
