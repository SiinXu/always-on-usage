# 只建草稿的 Etsy MCP，让 Grok Bot 安全上架

Source: https://github.com/GPTWorks/GPTWorks.github.io/pull/18

Author: GPTWorks

PR 新增一个只建草稿的 Etsy MCP，只有三个工具：建草稿商品、上传图片、读取商品；没有发布、改价或库存工具，每次写入前后对比在售商品快照，有变化就中止。OAuth 令牌留在自己的服务器，通过 Streamable HTTP 以自定义连接器接入 Grok。

What it does
The PR adds a draft-only Etsy MCP with exactly three tools: create a draft listing, upload an image, read listings. There are no publish, price or inventory tools, and active listings are snapshotted before and after each write, aborting on any change. OAuth tokens stay on your server; it connects to Grok as a custom Streamable HTTP connector.
