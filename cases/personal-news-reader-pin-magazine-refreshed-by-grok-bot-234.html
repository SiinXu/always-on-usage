Steps / points from the source
  1. Mark read / Remove persist in this browser only (localStorage: pnr_read, pnr_removed).
  2. Removed stories disappear from the feed; read stories are dimmed. Optional Hide read toggle.
  3. State is not synced across devices or browsers.
  4. data.json — live home feed (updated + stories[] with id = sha1 of URL). Hard cap: ≤20 stories after every publish. Prefer category variety; avoi
  5. archive.json — accumulating store of all known stories (append by id; never wipe). Used for Saved lookup, not the endless home pile.
  6. images/ — local thumbnails referenced by image_local.
  7. Refresh cadence: 7am / 11am / 5pm ET (not hourly).
  8. Format rules: ../profile/SITE-FORMAT.md.
