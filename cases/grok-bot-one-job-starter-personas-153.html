Steps / points from the source
  1. Pick a persona in personas/ or the full speed-to-lead/ kit.
  2. Create a Grok Bot / Cursor agent → paste SYSTEM / description from the file.
  3. Add skills from speed-to-lead/skills/ (for the STL desk).
  4. Connect one connector (usually Gmail).
  5. Run speed-to-lead/FIRST-WAKE.md once — drafts only, never auto-send.
  6. Never send mail/social unless the human says “send it”.
  7. Cap burn: one connector, narrow query, stop when the brief is done.
  8. No new KYC / Stripe / Whop from these bots.

Risks and limits
  • Involves payments, orders or bookings: let the bot draft first and act only after you confirm
  • Reads and writes your mailbox: grant read-only and draft access first, and approve before anything is sent
  • The author's result may not reproduce for you; the original post is the reference
