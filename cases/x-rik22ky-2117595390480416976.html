FindSafeHomes, a rental search built on Meta Muse Spark

@rik22kyX ↗Posted 2026-11-03Added 2026-11-03 13:34 UTC♥ 6

What it does
For the Meta Global AI Developer Hackathon, the author built FindSafeHomes: renters describe the home they want in natural language, Meta Muse Spark turns it into structured search criteria and pulls matching listings, and users can see each listing's agent and request inspections. Stack: React, Tailwind CSS, Node.js, Express, MongoDB.
