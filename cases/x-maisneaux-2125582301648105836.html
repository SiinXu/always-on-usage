# Red Tape Cutter：给臃肿的 Grok Bot 机器人群做减法

Source: https://x.com/maisneaux/status/2125582301648105836

Author: maisneaux

作者的 Grok Bot 机器人群出现了重复机器人、过于频繁唤醒的例程、转发链，以及向他索要连接器早已有的数据的提醒。他做了 Red Tape Cutter，审计每个机器人、规则和例程，按优先级列出可删项，只执行他选中的，现已作为免费模板发布。

What it does
The author's Grok Bot fleet had duplicate bots, routines waking too often, relay chains and reminders asking for data a connector already had. He built Red Tape Cutter, which audits every bot, rule and routine, ranks the cuts and applies only the ones he picks. It is now a free template.
