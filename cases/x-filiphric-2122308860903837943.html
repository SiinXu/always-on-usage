# 自建应用都接 MCP，让 Grok Bot 直接操作

What it does
The author is dropping subscriptions and has built his own email client, calorie tracker and other daily apps. Each has an MCP server, so he tells Grok Bot, Codex or another harness to read or write data, such as drafting and sending email inside a chat, and every change or bug fix is a prompt away.
