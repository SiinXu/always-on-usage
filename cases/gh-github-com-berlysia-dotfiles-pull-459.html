ask-grokbot: handing a local task to a Grok Bot webhook

berlysiaGitHub ↗Posted 2026-10-29Added 2026-10-29 12:46 UTC

What it does
This pull request adds an ask-grokbot command so a local coding agent can send a request to a Grok Bot routine webhook; on success it prints the reply file's absolute path, and --wait waits for the file's content. JSON is built with jq, the URL and authorization come from environment variables or a config file outside the repo, and --dry-run previews the payload without credentials. Tests stub curl and pass on macOS and Ubuntu; the author notes it has not yet been sent to a real webhook.
