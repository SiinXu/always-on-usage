iPhone Shortcut now sends to Grok Bot through the share sheet

jamespendryGitHub ↗Posted 2026-10-21Added 2026-10-21 12:42 UTC

What it does
A PR in send-to-grok-bot: the grokbot:// link only opened Grok Bot's home screen, so copied messages never reached a chat. The Shortcut now copies the message and opens the share sheet, where you tap Grok Bot, pick a chat and tap Attach. The iPhone page, README and BUILD.md were updated, the Shortcut re-signed and tests pass.

  2. Unzip it. Open your Downloads folder and double-click send-to-grok-bot.zip. You get a folder called send-to-grok-bot. Leave it there. On Windows, right-click……
  3. Open Chrome's extensions page. Copy this, paste it into the address bar at the top of Chrome, and press Enter:
  4. Turn on Developer mode, then click Load unpacked. Developer mode is a switch at the top right of that page. It lets Chrome load an extension from a folder on……
  5. Refresh. A card named Send to Grok Bot now shows on the extensions page. If you have x.com open, refresh it so the button appears.
  6. Send Grok Bot this line. Paste it into any Grok Bot chat:
  7. Open the routine. Click the bot's name at the top of the chat. Under Routines, click Send to Grok Bot.
