A teaching agent for Kenya's CBC curriculum built with Muse Code and Muse Spark

Moses-GithinjiGitHub ↗Posted 2026-11-03Added 2026-11-03 23:44 UTC

What it does
This hackathon repo builds an AI teaching agent for Kenya's CBC curriculum using Muse Code and Muse Spark. It produces schemes of work, lesson plans, exams and diagrams with exact KICD citations, an audit trail and teacher sign-off.
