CamToShop: film a product once, get a ready-to-sell package

cabetanGitHub ↗Posted 2026-10-29Added 2026-10-29 22:37 UTC

What it does
The GitHub project camtoshop turns one product video into a ready-to-sell listing package. It is built with Meta's Muse Spark, SAM 3.1 and Muse Image for the Meta Global AI Developer Hackathon.
