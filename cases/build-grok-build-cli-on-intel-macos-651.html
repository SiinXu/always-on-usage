Steps / points from the source
  1. no official macOS x86_64 prebuilt package;
  2. but the official Rust source can still be built locally;
  3. one build-time dependency (protoc) may need an external Intel-compatible binary;
  4. browser/device-code authentication may need explicit proxy environment variables on some networks.
  5. Rust + DotSlash as build requirements;
  6. protoc resolution through bundled bin/protoc, with fallback to protoc on PATH or $PROTOC;
  7. macOS and Linux as supported build hosts;
  8. the release binary target as target/release/xai-grok-pager.
