Steps / points from the source
  1. Even AI transcribes your speech and sends the text to your service.
  2. The service saves the question in SQLite and sends a signed MCP event to your subscribed Dot.
  3. Dot calls the plugin’s reply tool with the question ID and a short answer. If it arrives within 90 seconds, the service returns it on the original Even AI re……
  4. If Even AI displays “Question saved,” ask “What did Dot say?” to collect a late reply. If several questions timed out, repeat the phrase to collect ready rep……
  5. Open ChatGPT → Plugins → Add → Add custom MCP server. Name it Glasses inbox and use https://glasses.example.com/mcp as the server URL.
  6. Choose OAuth → Advanced OAuth settings → User-Defined OAuth Client. Set the client ID to g2-dot-link, the client secret to the value of DOT_CLIENT_SECRET in ……
  7. Create and connect the plugin. Enter DOT_PAIR on your own service’s pairing page.
  8. Open your personal Dot conversation and send the instruction below. Wait for Dot to confirm monitoring is active. ChatGPT plugin setup
