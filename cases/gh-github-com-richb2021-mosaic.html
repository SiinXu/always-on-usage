Steps / points from the source
  1. Live app: https://mosaic.richardbatt.com
  2. Game library (no sign-in needed): https://mosaic.richardbatt.com/modes.html
  3. 3D RPG, Lanternbound: https://mosaic.richardbatt.com/rpg.html
  4. Add your own material (notes, a PDF, Word, slides or a web page) and review it. Mosaic generates only from passages you've reviewed, and every activity cites……
  5. Turn a course goal into a route of objectives, then prepare an activity for each one in any format below.
  6. Nothing reaches learners until a person approves it.
  7. Create classes, invite pupils, and assign courses or chapters.
  8. See scores on the games you assigned (right first time, help used, retries), plus an inbox of work and help requests and a CSV export.
