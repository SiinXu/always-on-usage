Steps / points from the source
  1. The MCP server runs on the assistant’s machine (Grok Bot’s computer, or your laptop for Claude Desktop / Cursor).
  2. It calls Home Assistant’s normal API with HOMEASSISTANT_URL + HOMEASSISTANT_TOKEN.
  3. You do not need the Home Assistant MCP Server integration (/api/mcp) for this path.
  4. Run one ha-mcp install method only (stdio or HA App or in-process custom component — not several at once).
  5. Home Assistant reachable over HTTPS (or HTTP on a trusted LAN) from the machine that will run ha-mcp.
  6. Grok Bot agents run on a remote Linux “box.” Your HA URL must be reachable from the internet or a tunnel (Nabu Casa, reverse proxy, WireGuard, Cloudflare Tu
  7. uv / uvx on that machine (Astral uv).
  8. Python 3.13 available to uv (uv python install 3.13 if needed). Current ha-mcp expects 3.13.x.
