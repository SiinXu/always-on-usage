Steps / points from the source
  1. 릴리스에서 Dot-Pet-Setup-0.6.1.exe를 내려받아 실행합니다. 설치 없이 시험하려면 Dot-Pet-Portable-0.6.1.exe를 선택합니다.
  2. 모리 캐릭터를 클릭합니다. 기존 로그인 세션이 있으면 대화를 연결합니다.
  3. 처음 사용하면 열린 원본 대화 창에서 본인의 ChatGPT 계정으로 로그인하고 dot 대화를 엽니다. 화면 위의 연결 확인을 누르거나 캐릭터를 다시 클릭합니다.
  4. 말풍선에 입력하고 Enter 또는 보내기 버튼을 누릅니다. Shift+Enter는 줄바꿈입니다. 전송을 확인하면 ‘생각 중…’으로 바뀌고 답변이 표시됩니다.
  5. 입력 포커스를 뺏지 않고 약 15초 동안 표시합니다. 말풍선을 누르면 대화가 열리고 ×로 바로 닫을 수 있습니다.
  6. 캐릭터를 움직이거나 크기를 바꾸면 말풍선도 따라갑니다. 캐릭터를 숨기거나 대화창/원본 창을 보고 있을 때는 알리지 않습니다.
  7. 이전 대화, 내가 보낸 메시지, 이미 알린 메시지는 다시 알리지 않습니다. 여러 답변 말풍선은 모아서 보여줍니다.
  8. 약 3초 간격으로 확인하고 답변이 안정된 뒤 표시하므로 몇 초 지연될 수 있습니다. 앱 시작·페이지 재연결 직후에는 과거 대화를 먼저 불러옵니다.
