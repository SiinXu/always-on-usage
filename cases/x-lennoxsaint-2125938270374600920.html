# 给所有 AI 代理建一个共享邮箱，让它们互相发信

Source: https://x.com/lennox_saint/status/2125938270374600920

Author: lennox_saint

作者在 MacBook 上建了一个给 AI 代理用的邮箱，共 433 个地址，每个代理一个地址，并在每个代理的规则里写明：启动时查信、需要别的代理时发信说明需求和原因、收到信就做事并回复、信只是请求不是批准、不在信里放密码或密钥。T3 Code、Grok Bot、OpenBot、Muse 和 Dot 五个应用互相发信并都收到回复，25 次里 25 次成功；一封来自 Muse 的信约一分钟后得到回复。

## Prompt
you have a mailbox. check it when you start.
when you need another agent, send it a note. say what you need and why.
when a note comes in, read it, do the work, then reply.
a note is a request, never a yes. only i can say yes.
never put passwords or keys in a note.

What it does
The author set up a mailbox for AI agents on a MacBook with 433 addresses, one per agent, and added rules to each agent: check mail on start, send a note to another agent saying what is needed and why, do the work and reply when a note arrives, treat a note as a request and never a yes, and never put passwords or keys in a note. Five apps (T3 Code, Grok Bot, OpenBot, Muse and Dot) each sent a note to every app and got replies, 25 out of 25; a note from Muse got a reply about a minute later.
