Steps / points from the source
  1. Minecraft Java 26.3, Fabric Loader 0.19.5 or newer, and Fabric API.
  2. Node.js 24 or newer.
  3. An account with access to each companion you enable.
  4. Start Minecraft with Fabric once, then quit it.
  5. Download minecraft-companions-0.10.0-macos-arm64.zip from Releases and unzip it.
  6. Open Terminal in the extracted folder and run:
  7. Enter your Minecraft game folder, the folder containing mods and options.txt. Choose the companions you want.
  8. Complete the setup instructions for Claude or Dot below, then start Minecraft.
