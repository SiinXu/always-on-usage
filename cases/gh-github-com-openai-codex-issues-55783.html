# macOS 桌面版 ChatGPT 侧栏里的 Dot 不见了

Source: https://github.com/openai/codex/issues/55783

Author: Stahl-G

2026-10-21，macOS ChatGPT 桌面版 26.1016.51333 侧栏中已有的 Dot 消失，但同一账号在 Chrome 的 chatgpt.com/dots/home 上 Dot 仍可正常回复。日志有 Orbit catalog 任务元数据加载失败的警告（作者说明只是相关、非确定原因）；作者请求提供保留对话、本地任务和电脑授权的恢复方式。

What it does
On 2026-10-21, an existing Dot disappeared from the sidebar of ChatGPT desktop 26.1016.51333 on macOS, while the same account's Dot still replied normally at chatgpt.com/dots/home in Chrome. Logs showed Orbit catalog task metadata warnings (the author notes correlation only). The author asks for a recovery path that keeps conversations, local tasks and computer authorization.
