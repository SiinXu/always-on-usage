Steps / points from the source
  1. **Agent Platform:** Meta Muse (tool-calling via OpenAPI 3.1)
  2. **Edge Compute:** Cloudflare Workers (sub-100ms routing & security middleware)
  3. **Database:** Supabase (PostgreSQL with PostgREST auto-generated REST API)
  4. Create a free database project at supabase.com.
  5. Open the **SQL Editor** tab and execute all commands from `schema.sql`.
  6. In **Project Settings** → **API**, copy:
  7. **Project URL** (`https://.supabase.co`)
  8. **Service Role Key** (`sb_secret_...` or service role JWT)
