Steps / points from the source
  1. local_lead_ingest.py — pulls InkFreeNews (WP JSON), KEDCO (RSS), Times-Union homepage headlines, chamber calendar (best-effort). Scores with geo + SMB signa
  2. lead_inbox.py — wraps ingest with durable state so morning digests only surface new (or score bumps), not the same Autocam/Wingstop story every day.
  3. fetch_article_text.py — optional plain-text fetch for top links (no browser).
  4. lead_inbox_latest.json / .md
  5. lead_inbox_state.json (gitignored)
  6. Times-Union RSS returns 403; homepage scrape only.
  7. Free/local HTTP only. Close browser tabs when done; prefer scripts over browser.
