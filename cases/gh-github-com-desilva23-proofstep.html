ProofStep: checking procedure steps from video

desilva23GitHub ↗Posted 2026-10-29Added 2026-10-29 12:46 UTC

What it does
The GitHub project proofstep checks from video whether each step of a physical procedure was done, and says when it can't verify. It uses Muse Spark and SAM 3.1 on the Meta Model API.

  4. The evidence shown is the in-hand stretch closest to Spark's time. Moments inside another step that uses the same object belong to that step.

  6. Order rules are checked only between verified steps.
