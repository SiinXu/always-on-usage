What it does
The repo is a personal project harness for Grok Bot, mostly automated: it integrates with a local Build, with key automated approval steps, automatic escalation to the user for approval, Build plan review and modification, and upload to GitHub.

Steps / points from the source
  1. Project Group — discussion and quality control (Critic, Expert, Advocate)
  2. Forge — production (Coordinator, Engineer, Advocate, optional Policy and Demo)
  3. Clear hand-offs, plan-review gates, and escalation paths
  4. Local Grok Build integration (headless plan → review → approved implementation)
  5. GitHub push under your author name after clearance
  6. Optional progress routines that stay silent when nothing is active
  7. Copy harness-template.md and fill in the fields.
  8. Paste the completed template (the whole file) into a Grok conversation.
