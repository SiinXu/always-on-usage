A memory layout for running Hermes, Grok Bot and OpenClaw together

@webjuice_ieX ↗Posted 2026-11-10Added 2026-11-10 13:42 UTC

What it does
The author's agency runs three agent setups (Hermes, Grok Bot, OpenClaw), and every new seat needed the same briefing. Memory now lives in three places: an Obsidian vault for rules, notes and daily logs shared by all three; Google Drive for client files; and Honcho for what agents learn, with the vault winning on conflicts. Rules: each setup has its own folder and never edits another's, one client per setup, logins only in a password manager, an append-only learnings file tagged by author, and nothing goes out without approval.
