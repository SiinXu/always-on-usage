Giving a homelab Grokbot all 33 MFP tools

carpenikeGitHub ↗Posted 2026-11-11Added 2026-11-11 23:43 UTC

What it does
This PR gives the Grokbot view of a homelab MCP service all 33 MFP tools, including reads, writes and deletes, chosen by the repo owner over two narrower options. The author spells out the risk: every write is still preview first, then confirm with a time-limited token, but nobody looks between Grok's preview and confirm, so a misread request could change or delete diary entries, and deletes are not recoverable. The fix if needed is to drop the delete tools.
