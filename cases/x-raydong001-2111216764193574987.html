Daily private GitHub backup of a Grok Bot computer

@Raydong001X ↗Posted 2026-10-16Added 2026-10-16 22:44 UTC

What it does
Following another post, the author auto-backs up a Grok Bot computer to a private GitHub repo daily; first push about 1200 files, 78MB. They use gh device-code login (no token in chat), confirm the repo is private, back up skills, routine logs, drafts and handoffs, exclude secrets and large media, and scan for sensitive strings before push. Skills and rules matter more than the machine itself.

Steps / points from the source
  1. Login with gh device code (no token in chat); complete GitHub 2FA; device code expires in 15 minutes
  2. Create a private repo; confirm PRIVATE with gh repo view before push
  3. Back up: skills, routine logs, drafts, handoff files, research notes
  4. Do not back up: .env, tokens/secrets/cookies, key files, databases, personal originals, audio/video over 20MB
  5. Scan for sensitive strings before push (ghp_, sk-, AKIA, BEGIN PRIVATE KEY, Bearer, api_key=)
  6. Schedule: auto run daily at dawn; push immediately when skills/rules change; skip if unchanged
