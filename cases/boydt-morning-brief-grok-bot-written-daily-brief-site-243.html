Steps / points from the source
  1. GitHub raw, pinned to the latest commit on main. The page resolves the commit with one call to api.github.com/repos/boydt/morning-brief/commits/main and t
  2. Commit-pinned URLs never go stale.
  3. Plain raw…/main/… is cached by GitHub's CDN for up to 5 minutes, even with a unique ?t= query.
  4. dataBaseUrl itself (raw main, cache-busted). The page uses this when the GitHub API is unavailable, for example because of its limit of 60 unauthenticated
  5. GitHub contents API (application/vnd.github.raw), as a secondary source.
  6. The bundled data/ copy that ships with the published site, reached by relative paths. The top bar then shows a subtle "⚠ Offline copy" note.
  7. when the page opens;
  8. when Boyd taps ↻ Refresh in the top bar, which re-fetches without reloading, re-renders only the headline cards that changed, and keeps the reading position
