来源里的步骤 / 要点
  1. Web inbox with threads, search, compose, and labels
  2. Optional AI agent on Workers AI
  3. MCP at `/mcp` for Grok Bot and other MCP clients
  4. Mailbox Bearer tokens so bots can call MCP without wrapping `/mcp` in Cloudflare Access
  5. Optional aliases and send-as addresses on one mailbox, such as `user+label@example.com`
  6. Configurable catalog models through `AGENT_MODEL`, `INJECTION_MODEL`, and `VERIFIER_MODEL`
  7. In the browser, create or select an operator-owned GitHub fork or private copy. Do not clone the template onto Grok Bot's shared computer.
