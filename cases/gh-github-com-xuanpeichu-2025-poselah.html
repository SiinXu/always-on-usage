PoseLah: an AI photo coach in the phone browser

What it does
The GitHub project PoseLah is an AI photo coach that runs in a phone browser: it scans the scene, finds the best light and angle, then has you match a pose outline. It is built with Meta's Muse Spark and SAM 3.1.
