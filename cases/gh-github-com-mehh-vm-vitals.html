Steps / points from the source
  1. Open vm-vitals.vercel.app and click Copy prompt for your Grok Bot. That mints a one-time pair token, bakes it into a prompt and copies it.
  2. Paste it to your bot. Grok Bot, Claude Code, Codex, anything that can run a shell command. The prompt looks like this, with your token in place of the x's:
  3. Wait. The page you copied it from listens for the pairing and jumps to your dashboard when the first heartbeat lands, usually within a minute.
  4. Flip Public page on the dashboard, hit Copy link, and send it to your friends. The link unfurls into a live card.
  5. A health score from 0 to 100 and a mood: thriving, humming along, sweating a bit, wheezing, flatlining, or gone quiet. Grok Bot's face and antenna light foll……
  6. The crew. Chip watches CPU and load, Mimi watches memory and swap, Stash watches the root disk, Ping watches the network. Each one fills up with its number, ……
  7. Charts for the last hour, 6 hours, a day or a week.
  8. Alerts for full disks, memory pressure, swap, runaway load, OOM kills, agent jobs that died, and machines that went quiet.
