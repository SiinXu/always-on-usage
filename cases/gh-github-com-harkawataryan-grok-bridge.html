Steps / points from the source
  1. Through your desktop (recommended, nothing exposed): keep Claude Desktop running on
  2. As a custom connector: run node server.mjs --http 8790 and expose it with a
  3. It drives the UI, so a Grok Bot update that renames its CSS classes
  4. While the debug port is open, any program on this PC can control the Grok Bot window.
  5. There's no "stop the bot" tool: the app has no stop control I could verify.
  6. node test-client.mjs runs a quick self-test, which sends one test message to the open bot.
