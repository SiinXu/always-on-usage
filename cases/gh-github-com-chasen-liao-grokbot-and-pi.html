GAP: using Pi as a Grok Bot subagent

Chasen-LiaoGitHub ↗Posted 2026-11-11Added 2026-11-11 23:43 UTC

What it does
The open-source project GAP (Grokbot And Pi) uses Pi as a Grok Bot subagent via pi-task (RPC), with webhook wake and a disaster-delete guard.
