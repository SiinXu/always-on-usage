Steps / points from the source
  1. Two-way messaging — Send requests and receive replies or push messages from dots.
  2. Async callbacks — Register @bridge.on_received handlers and keep sending and receiving independent.
  3. OpenAI-compatible interfaces — Use Chat Completions REST/SSE and Responses WebSocket clients.
  4. Start registering a custom MCP server on the plugins page. Use https://YOUR-DOMAIN.ngrok.app/mcp as the MCP URL and select OAuth authentication.
  5. Copy the exact OAuth callback URL shown during registration into redirect_uri in bridge.toml. Stop serve with Ctrl+C and restart it.
  6. Register and connect using the values below. Enter owner_key from bridge.toml on the bridge's consent page.
  7. Your application sends a request. The bridge stores it in SQLite and returns a request_id.
  8. The bridge delivers an app.message.created event to the subscribed dot over HTTPS.
