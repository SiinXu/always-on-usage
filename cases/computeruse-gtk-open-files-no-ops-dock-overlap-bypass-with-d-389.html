What it does
Staff (deanrie, 2026-09-06): On the Bot computer, GTK “Open Files” Open/Cancel often sit on the bottom dock so clicks hit the dock and the dialog no-ops (file itself is fine)—ask the Bot to set the page file input via DevTools DOM.setFileInputFiles to a /home/box/... path (no dialog), or drag/maximize the dialog so Open clears the dock; known dialog-geometry issue, tracked.
