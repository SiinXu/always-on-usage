Missing features listed by a daily Dot user

What it does
The author, who uses his Dot over an hour a day via calls, lists gaps: purchases on the cloud computer are painful (he wants QR codes opened as URLs and a way to give Dot a limited virtual card via a secure form); music stops during calls; Dots used to send Slack messages but can now only draft them; refusals are too frequent and get remembered; he wants cloud MCP servers attachable via a config file and multiple computers attached permanently; WhatsApp access doesn't work properly; Dot never pings him back about tasks; computer use on calls is laggy; and the Uber Eats plugin forgets it is connected and tries the restaurant's web form.
