Steps / points from the source
  1. Python 3.11+, macOS or Linux, and uv.
  2. grokbot CLI, independently logged in
  3. Compatibility caveat: the bridge needs rpc --stream support. Verify your
  4. Weixin: direct HTTPS JSON calls using Python urllib to the iLink bot protocol
  5. Install a compatible CLI from the project linked above. Follow its build/login
  6. In this directory, run uv sync --locked.
  7. Copy config.example.toml to config.toml. Set the CLI path, profile, exact cloud bot name,
  8. Supply secrets through environment variables, not tracked config files.
