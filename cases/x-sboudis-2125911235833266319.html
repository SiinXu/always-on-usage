# 让 Grok Bot 例程在无事可做时不耗用量

Source: https://x.com/sboudis/status/2125911235833266319

Author: sboudis

作者指出 Grok Bot 很耗用量：每小时跑一次的例程可能一天就用掉一周的额度。他的做法是保持同样的例程，但在没事时消耗零 token：由一台 Mac 只在有活时唤醒 Grok Bot，繁重工作交给 Claude 或 Codex。帖子附有具体做法链接。

What it does
The author notes that Grok Bot is hungry: an hourly routine can burn a week of usage in a day. The approach keeps the same routines but uses zero tokens when there is nothing to do: a Mac wakes Grok Bot only when there is work, and Claude or Codex do the heavy lifting. A link to the how-to is in the post.
